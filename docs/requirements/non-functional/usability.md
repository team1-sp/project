# Usability Requirements

- **srs.nfr.1.1** Every discrete command of the Editor's menus, toolbars and context menus shall have a menu path, and save, undo, redo, duplicate, delete, rename, Play/Stop, pause, step and frame selected shall always allow a keyboard shortcut (srs.fr.27.35).
- **srs.nfr.1.2** Every action that permanently deletes project content, or discards unsaved authoring changes or a user layout, shall either be undoable or ask for confirmation first; stopping Play mode (srs.fr.17.25) and clearing the Console are not such actions.
- **srs.nfr.1.3** Every error message shown to the user shall, in plain English, name the item affected, say what went wrong and why, and say what the user can do next; when the user cannot correct it, the message shall say whether the operation can be retried and where the log is. An internal error code may follow the text but not replace it.
- **srs.nfr.1.4** At every Editor UI scale offered in Preferences (srs.fr.27.31), no text shall be clipped or overlap and every control shall be reachable, scrolling allowed.
