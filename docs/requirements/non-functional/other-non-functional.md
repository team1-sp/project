# Other Non-Functional Requirements

## Documentation

- **srs.nfr.6.1** The formats of the scene file, telemetry export, Semantic Graph export and headless run report shall be documented so that other tools can read them.
- **srs.nfr.6.2** Every built-in component type shall have a documentation page that the Editor can open (srs.fr.22.21).

## Localization

- **srs.nfr.6.3** The user interface shall be in English.
- **srs.nfr.6.4** All user-visible text shall be kept separate from code so that other languages can be added later.

## Privacy

- **srs.nfr.6.5** Aegis shall not collect personal identifiers; anonymous usage data is limited to srs.fr.13.61.
