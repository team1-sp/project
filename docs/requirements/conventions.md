# Requirement Conventions

- **Identifiers.** Each requirement has the ID `srs.fr.<group>.<number>`, following the `ip.fr.<group>.<number>` format of the Initial Plan. Section 6.4 maps every ID to its use case, user story and Initial Plan requirement.
- **Keywords.** Following ISO/IEC/IEEE 29148:2018, *shall* marks a mandatory requirement, *should* a desirable one and *may* an optional one.
- **System names.** *The Engine* is the runtime (ECS, physics, rendering, input, headless mode, telemetry). *The Editor* is the desktop application in which the user builds games. *The Hub* is the Editor's project launcher. *The Physics Adapter*, *the Semantic Architecture Layer* and *the AI Assistant Layer* are the components named in the Initial Plan. *The user* is the game developer using the Editor.
- **Screen references.** Codes such as A-01, C-05 or F-07 name frames of the Aegis Editor UI design: A = Project Hub, B = main window states, C = panels, D = menu bar menus, E = context menus, F = dialogs and notifications. A code ending in *b* or *c* is a variant state of the same frame.
- **Examples.** Collectible, Unlockable and Objective are abstract gameplay roles, not specific objects. Section 6 explains them with the key, door and goal metaphor of the Initial Plan.
- **Simulation ticks and render frames.** A *simulation tick* (tick) is one fixed update of 1/60 s of simulated time that runs the tick phases of srs.fr.1.12. A *render frame* is one drawing and presentation cycle in normal mode; it runs zero or more ticks (srs.fr.1.3). Headless mode runs ticks only. Tick numbers, tick counters and tick ranges identify simulation state, and the Editor labels them "Tick"; render frames are used only for drawing, FPS and render frame time. A *tick number* identifies one executing tick, starting at 0; *ticks executed* and a run's or recording's *length* count completed ticks, so a run of N ticks executed completed ticks 0 to N − 1 (srs.fr.1.19).
- **Entity IDs.** An *entity ID* is the stable whole-number identity of an entity, unique across the project's scenes and the loaded entities (srs.fr.2.62 to srs.fr.2.67).
- **Shortcuts.** Shortcuts are given for Windows. On macOS, Ctrl is replaced by Cmd (srs.fr.14.6).
